# Gimnasio Virtual

## Descripción
Gimnasio Virtual es una aplicación móvil desarrollada en Kotlin que permite a los usuarios registrarse, iniciar sesión y consultar diferentes rutinas de ejercicios.

## Funcionalidades
- Registro e inicio de sesión.
- Cierre de sesión.
- Consulta del perfil del usuario.
- Visualización de rutinas de fuerza, cardio, abdomen y estiramientos.
- Consulta de detalles y ejercicios de cada rutina.
- Entrenamiento con cronómetro, pausa y reanudación.
- Pantalla de finalización del entrenamiento.

## Tecnologías utilizadas
- Kotlin
- Android Studio
- XML
- Firebase Authentication
- Cloud Firestore
- Gradle

## Instalación
1. Clonar el repositorio.
2. Abrir el proyecto en Android Studio.
3. Configurar Firebase y agregar el archivo `google-services.json`.
4. Sincronizar Gradle.
5. Ejecutar la aplicación en un dispositivo o emulador Android.
